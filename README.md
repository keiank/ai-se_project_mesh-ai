# Mesh AI

Upload PDF documents to create a personal knowledge base. Use AI (RAG) to extract answers from your knowledge base.

## Technologies

- TypeScript
- Node.js
- Express.js
- Nebius API
- OpenAI TypeScript API library
- RAG (Retrieval-Augmented Generation)
- Embedding Models
- JWT (JSON Web Token)
- Bcrypt
- Mongoose
- MongoDB
- Multer
- JSDoc
- Prettier
- ESLint
